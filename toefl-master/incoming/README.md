# Incoming discussions (hand-off queue)

Files `gsat-NN.json` are Academic Discussion tasks written by the 學測英文作文講義 revision task
(unit NN of Jennifer's GSAT essay handouts). Each file is a `TOEFL_DISCUSSIONS` entry without `"no"`,
plus `"source"`. Markup: `[[...]]` = universal pattern (yellow), `**...**` = theme word (bold).

The hourly "TOEFL 2026 master" task publishes them (oldest first, up to 4 per run) as the next
Discussion numbers in their own `category`, exactly like its own discussions, and deletes the file
in the same commit. Do not edit this folder by hand.
